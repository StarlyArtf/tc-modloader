#
# The definition is one Input Pin wired straight to one Output Pin, so whatever

# Mod writes this section into every board record it produces (`defcustom` /
# `defcomponent` / `defwire`, each line ending in `def=0x<prototype id>`), and a
# viewer that ignored it could only refuse a board with a foundry component on
# it - which is exactly what it used to do.
