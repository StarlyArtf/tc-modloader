# SoftFloat 3e sources the float-ops kernel needs: binary16, binary32 and
# binary64 arithmetic, the integer conversions in both directions and the
# helpers they share.
#
# This is the transitive closure of the symbols the kernel calls, not a
# hand-picked list: the whole upstream source tree is compiled once, each
# object's defined/undefined symbols are read with nm, and the reference
# graph is walked from the kernel's entry points.  Files outside that
# closure - the extF80/f128 families, their helpers, and f16/f32/f64_eq/lt/le
# because the kernel implements comparison and classification itself - are
# neither vendored nor compiled.  See third_party/berkeley-softfloat-3/README.md
# for the upstream commit and the procedure; the integer conversions and the
# binary16/binary64 families joined the list with the width cut.
