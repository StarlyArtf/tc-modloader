# SoftFloat 3e sources the binary32 kernel needs.
#
# This is the transitive closure of the symbols fp/fp32.cpp calls: every file
# below was picked by compiling the whole upstream source tree once, reading
# each object's defined/undefined symbols and walking the reference graph from
# those entry points.  Files not listed here (f16, f64, extF80, f128, their
# helpers, and even f32_eq/lt/le, because the kernel implements the project's
# compare and classify itself) are neither vendored nor compiled.  See
# third_party/berkeley-softfloat-3/README.md for the upstream commit and the
# exact procedure; the integer conversions joined the list with the M4
# catalogue (f32_to_i32/f32_to_ui32/i32_to_f32/ui32_to_f32 and the two rounding
# helpers they need).
