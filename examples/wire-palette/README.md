# 导线调色盘 1.0.1

需要 TC Mod Loader 0.3.0，适配当前 Windows x64《Turing Complete》2.1.334 构建。

## 使用

1. 将 local.wire-palette.mod 放到游戏根目录 mods，在 Mods 页面勾选并应用，然后重启。
2. F7 显示／隐藏调色盘。进入关卡，把鼠标移到电路区域一次以连接绘图工具。
3. 用调色盘调 RGB／HSV，或输入十六进制颜色。松开鼠标／结束编辑后自动使用和保存，也可点“使用当前颜色”。之后绘制的新导线使用该颜色；已有导线可以用游戏原有改色操作重新着色。
4. 点击“取色器”，再点击已放置导线的中心。读回的是导线记录的颜色，不受亮暗、信号状态和截图色差影响；该次点击只取色，不放置或改色。Esc 取消。
5. 最近 5 种自定义颜色显示为色块，点击即可复用；重复颜色去重，新调色排在前面，重启保留。

## 数据与备份

永久颜色表和最近 5 色保存在：

tc-modloader-data/plugin-data/local.wire-palette/palette.json

颜色编号写入游戏正常电路存档，RGB 对照表单独保存。移出“最近 5 色”的颜色仍保留，旧导线不会变色，并可重新取色。请把 palette.json 与 Mod 存档一起备份；分享使用自定义颜色的电路时也需要携带相同对照表，不可直接覆盖别人已有的颜色表。

此版本使用游戏的一字节颜色编号，保留原版 0–10 和 255，共支持 244 种不同的永久自定义颜色。达到上限会拒绝新增，仍能复用旧颜色，不会回收编号或改变旧导线。

停用 Mod 会恢复原版着色器，自定义色无法由原版准确显示；重新启用并保留原 palette.json 可恢复。不要在停用期间用原版覆盖这些电路。丢失颜色表的编号用洋红色提示，不会猜测原颜色。

加载器的存档隔离继续生效。本 Mod 不访问原版存档。

## 开发与验证

构建：在完整源码目录运行 build-wire-palette.ps1。正式构建不定义 TC_WIRE_SELFTEST。

实现：精确文本补丁为导线线段及接头着色器加入 RGB 调色表；DLL 上传调色表，扩展游戏颜色预览表，Hook 原生导线输入处理，调用游戏 pipette_wire 取色。

验证：最近五色、去重、编号稳定、文件保存重载和容量上限测试通过；实机确认两组导线着色器正常工作，真实导线由原版编号改为自定义编号 11，取色读回 11，退出重开仍读取 11；将该颜色移出最近五色后，取色处理依然恢复原色并消费点击而不改动导线。开发自动化在独立 USERPROFILE 的电路副本中运行。

未穷尽验证所有复制粘贴／导出格式、所有显卡、多种修改相同导线着色器的 Mod 组合；修改同一资源的其他 Mod 会被加载器判定冲突。

## 1.0.1 黑色导线修复

修复选定自定义颜色后，拖动及放置导线仍为黑色的问题。在本机 Intel OpenGL 4.6 驱动 31.0.101.5445 上复现：glProgramUniform3fv 上传后查询 RGB 正确，但导线实际像素为黑色；改用 glUseProgram + glUniform3fv，上传后恢复原先绑定的程序，实际导线恢复颜色。

删除按缓冲区长度猜测并改写最后一个颜色字节的 Hook；隐藏状态的自定义线使用自身永久颜色，不随当前选择改色。颜色选择立即标记待上传，移除跨帧无条件写旧绘图上下文。

开发用 TC_WIRE_SELFTEST + TC_WIRE_RENDER_SELFTEST 在隔离的沙盒副本中注入拖线操作并读取 framebuffer 像素，检查拖动预览、放置和切换选色后的旧线。该测试依赖既有沙盒夹具及其视角，不在正式 DLL 中启用。
