# Archived gate-delay source rewrite

This directory contains the retired sandbox gate-delay implementation. It
rewrote the game's emitted program, temporarily cut feedback connections, and
added a loader-owned Options-page switch.

It is retained only for research and regression archaeology. Nothing under
this directory is compiled, packaged, registered in the test catalog, or
loaded by the game. The active replacement is `examples/sandbox-sim`, backed
by `simcore`.

Archived material keeps its original `src`, `tests`, `tools`, and `docs`
layout so the implementation and its evidence remain together.
