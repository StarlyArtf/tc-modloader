# TC Mod Loader 0.8.5

本版本将通用仿真加速内置到加载器，默认启用，安装升级后即可用于原版电路。

- 优化游戏生成的 x64 JIT 程序，减少冗余复制、移位、掩码和栈写入；未录制波形时跳过采集外调，宽常量直接读取稳定原子槽。
- 扩展 TC-Verilog 的模块、参数、generate 和组合块支持；符合条件的组合核直接生成游戏 JIT 表达式。
- 修复原版 Keyboard 的键码与按键状态输出。
- 扩展元件编辑器、组合网表、生命周期、Mod 设置与存储接口，更新 SDK ABI 基线。
- 更新单窗口安装器；源码包包含构建所需的 simcore 与图标目录。
- 修复已识别旧版加载器的直接卸载，以及精确依赖元件内部接线的误连；保留有效原始引擎备份校验。

实际仿真 MHz 随电路、机器和运行负载变化，不保证固定达到 20 MHz。可设置 `TC_MODLOADER_JIT_OPT=0` 关闭额外 JIT 优化作对照。

支持《Turing Complete》2.1.334 的指定 Windows x64 构建。请关闭游戏后运行 `TCModLoader-Setup.exe` 升级；安装器会识别兼容性画像。完整玩家包包含安装器、CLI、SDK、文档、示例 Mod 和源码包；`SHA256SUMS.txt` 提供校验。

详细实现与历史记录见 [版本历史](https://github.com/StarlyArtf/tc-modloader/blob/v0.8.5/docs/changelog.md)。
