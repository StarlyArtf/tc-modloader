## 1. 撤销分组

**想解决的**：Mod 一次盖下一整块电路（几十个元件）之后，玩家想撤掉它得按几十次 Ctrl+Z。

**第一步**：核实 `add_undo_changes__modelZboardZboard_u23805` 到底是什么。两种结果对应两条路：

- 如果它就是游戏的"记账点"（游戏本来就按"一次操作"记一笔），那 Mod 顺着那条路走就自动分组，
  我们**什么都不用加**；
- 如果游戏是按单次改动各记一笔，那才轮到考虑给 Mod 一个显式的"这批算一步"。

**依赖**：先有删除/移动。现在连删都做不到，分组是"给还不能倒车的车装倒车雷达"。

**红线**：不要用帧或时间窗口去猜"一批"的边界——猜错很难查，Mod 慢一帧就散了。

**状态**：2026-09-20 由用户决定搁置，排在删除/移动之后再看。

## 2. 让游戏选中（写选择集）

**想解决的**：现在只能"读"玩家选中了什么（波形类 Mod 靠这个盯住玩家选中的那根线），但不能反过来
让游戏选中某个东西。于是 Mod 想说"你这块电路有个输出没接"时，只能给一个坐标让玩家自己找。

**第一步**：核实候选符号的签名（先反汇编看参数布局，再写真机探针打行为，最后才进契约）：

| 符号 | 猜测 |
|---|---|
| `select_component__modelZboardZboard_u9202` | 选中一个元件（最直接） |
| `incl__…_u17136` / `incl__…_u2245` | 集合加入（很可能是元件集/导线集各一个） |
| `excl__…_u21312` | 集合移出 |
| `clear_selections__…_u8323` | 清空两个集合（参数最少，最容易先试） |
| `get_selection__…_u9061` | 取当前选择 |

**顺带收益**（这也是它比别的项划算的原因）：

- **高亮**：游戏自己会给选中项上色，所以"能选中"等于白拿一个低配高亮；
- **面板跳转**：列表里点一行 → 游戏里选中它；
- **借用游戏自己的工具**：选中之后玩家可以直接按 Delete 删、按 R 旋转、用游戏的连线工具
  ——绕开了"还没有删除接口"这件事（代价是最后一下得玩家自己按）；
- **`SELECTION_CHANGED` 事件**：有了写入口，这个已经写好但没真机触发过的事件才有东西可验。

**状态**：线索已备（见 [research/board-object-fields.md](research/board-object-fields.md) §5），未开工。

## 3. 棋盘上的高亮／标注／镜头

拆成三小项，因为它们的入口不同：

| 小项 | 想要的效果 | 需要什么 |
|---|---|---|
| 高亮 | 让某个元件/导线在棋盘上显眼 | 低配版可由"让游戏选中"免费得到；要"多个目标、不同颜色"就得另找渲染入口 |
| 标注 | 在这根线／这个元件旁边画字或图形 | 需要"棋盘坐标 → 屏幕像素"的换算，依赖相机的缩放与平移状态 |
| 镜头 | 自动对准某点或框选区域 | 需要相机控制的入口 |

**第一步**：先把**相机状态**找出来（缩放/平移存在哪、怎么读）。标注和镜头都要它；找到之后
标注可以先只做只读的坐标换算，不需要改任何游戏状态。

**状态**：未开始。
