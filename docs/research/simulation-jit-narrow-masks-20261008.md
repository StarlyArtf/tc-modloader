# 原版仿真窄位宽计算合并（2026-10-08）

继续优化已安装的常量移位版（E2967B91…）。本轮针对游戏原版仿真编译器生成的窄位宽截取代码，未修改 TC-Verilog 内核、速度显示或仿真批次调度。

## 实现

生成程序常用左移再逻辑右移保留低位，例如 `(x << 56) >> 56` 保留低 8 位。对于有效计数 N≥32，这一计算可以用 `AND r32, (1 << (64−N))−1` 完成。32 位 AND 会清除高 32 位，因此 N=32 也正确；若改成带符号扩展立即数的 64 位 AND，掩码 `0xffffffff` 会错误保留高位，本实现没有这样做。

规则只匹配五条保留指令：`MOV ECX,N; SHL r64,CL; MOV RCX,r64; MOV ECX,M; SHR 同r64,CL`。要求 N/M 的有效计数一致，目标不是 RCX/RSP，并且最后一次移位的全部算术标志位随后被覆盖，期间没有标志位观察者、控制流或未知指令。保留完整的末次 MOV ECX，删除首次计数赋值、中间复制和第二次移位；剩余一次 AND 和末次计数赋值。

按上一轮删除 pass 的保留指令匹配，目标保护则检查整个原码跨度，包括被删掉的自复制。禁止任何入口、直接调用或分支跳入原序列中部。代码长短改变后沿用完整重定位；不支持的程序及短跳转越界仍整块回退原码。

第一版只按原始相邻指令匹配，真实编译日志显示命中 0 次；新增带逆向复制的失败用例，改为匹配保留指令后通过。第一版状态对比虽一致，但并未执行新规则，测速已中断，不作为性能证据。测试脚本增加可选 `ExpectedCandidateJitPattern`，本轮要求日志包含非零 narrow masks，避免再次验证到未命中的候选。

冻结原版 Overture CPU（111 个实际元件，展开后 125 个节点）真实日志显示合并 **260 处**：累计删除 2,163 条指令，另保留 140 处单独的常量移位替换，程序 83,459 → 76,893 字节，入口 8,495 → 7,856。上次安装版为 79,966 字节、入口 7,886。本轮额外删除 780 条指令，位宽截取由两次移位变成一次掩码。
