## 改变与边界

在现有优化之后分析每个物理寄存器的哪些位会被后续观察。直接 JMP 跟踪目标；条件跳转合并两条后继；回边迭代到固定点。未知指令、CALL、RET 都保守要求所有寄存器的所有位，已有删除按 NOP 处理。

- 完整寄存器复制把目标所需位反向传播到源；32 位零扩展、MOVZX 只传播相应源位。
- AND 立即数只读取掩码保留位；MOVSX 读取对应低位或 AH 等高字节。
- 字节 CMP/TEST 读取真正的字节，内存基址和索引仍需要完整 64 位。
- 其他指令保守使用已有物理寄存器读写效果；部分写入不会当成完整覆盖。
- 图超过 32,768 条或 64 轮内未收敛，完全跳过这项新分析，不使用半成品结论。

固定点完成后仅删除三类：同寄存器符号扩展且改变的高位不再使用；AND 且改变位不再使用并且原有完整 flags 覆盖证明仍成立；完整 64 位寄存器复制且目标所有位不再使用。RSP 目标、内存读写和 Boolean MOV 0 初始化不由本 pass 删除。

没有修改游戏计数、显示速度、线程调度、电路或共享状态协议。

## 离线与执行校验

同一份 83,459 字节原始 JIT 捕获：v8 为 63,013 字节，v9 为 **62,756 字节**，入口 6,350 → 6,341。新增删除 **31 条无用符号扩展、13 条掩码、17 条复制**，共 61 条。代码减少不直接证明速度提高，安装以实测收益为准。

由完整单行反汇编统计 Overture 热循环：v8 地址 29126..39134，共 2,053 条；v9 地址 29111..38901，共 **2,005 条**。其中 SHL/SHR/SAR 都为 90 条，MOVSX/MOVSXD 从 38 降为 **7 条**，RSP 引用都为 560 次。61 条新增删除中有 48 条位于这段循环；仍有明显的栈读写开销。

新增执行测试先 RED 后 GREEN；现有机器码测试全部通过。包括双分支覆盖、单路径仍使用高位、64 位比较、AH、未知 CALL、地址寄存器读取、回边 1,000 个随机值 × 两种高位保留/删除情形，以及超大图和超过迭代上限的保守回退。

一项旧测试的计数由 1 改为 2：原来的最后逆向复制仍可删除，新增分析又发现跳转之前写入 RCX 的复制在目标被覆盖；精确断言增加 `flowCopies=1`，实际值对照保留。修正新测试未给 R9 初始化的返回分支，改用已有输入 RCX，确保两次调用可比较。
